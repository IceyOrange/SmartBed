# 护理床端侧语音交互演示设计

## 目标

在现有家属端 MVP 之外增加一个独立的“护理床端侧语音交互演示”页面，用于现场展示用户如何通过自然语言调用护理床 Agent。页面只模拟识别、决策和执行反馈，不连接真实床体、联系人、护理系统、天气服务或媒体服务。

家属端仅提供一个明确标注为“演示”的超链接。演示页不属于家属端的三项底部导航，也不提供家属远程控制床体的能力。

## 入口与页面边界

- 家属端入口位于“我的 → 设备与隐私”区域，名称为“床侧语音交互演示”。
- 链接在新标签页打开 `/voice-demo.html`，避免用户误认为它是家属 App 的正式功能页。
- 演示页提供“返回家属端”链接。
- 页面默认以床旁屏幕体验设计，同时适配桌面浏览器和平板、手机窄屏。
- 所有执行结果都显示“模拟执行”标记，危险动作不显示为真实设备已完成。

## 核心交互

### 输入方式

1. **真实麦克风输入**
   - 用户点击主麦克风按钮后请求浏览器录音权限。
   - 优先使用浏览器 Web Speech Recognition 能力将普通话转为文字。
   - 识别中展示实时状态；识别完成后自动提交给意图引擎。
   - 再次点击可停止识别。

2. **文本输入兜底**
   - 页面始终保留文本输入框和发送按钮。
   - 浏览器不支持语音识别、权限被拒绝、没有检测到语音或识别报错时，明确提示原因并将焦点移到文本输入框。
   - 示例话术点击后直接提交，便于无麦克风环境下演示。

### 输出结构

每次输入形成一条可展开的交互记录，按低认知负担顺序展示：

1. 用户原话；
2. Agent 的自然语言回复；
3. 当前状态，例如“需要确认”“模拟执行中”“已模拟完成”“仅提供信息”；
4. 可展开的“Agent 如何理解”区域，展示功能域、识别意图、参数、处理路径和安全策略。

页面顶部保留当前会话摘要，例如“正在等待指令”“需要确认：床体复位”“正在模拟通话”。

## 意图模型

### 一、身体自主：床体控制

| 意图 | 典型表达 | 抽取参数 | 模拟响应 |
| --- | --- | --- | --- |
| 紧急停止 | “停”“马上停下”“床别动了” | 无 | 立即中断当前床体动作，最高优先级，无需确认 |
| 靠背调节 | “把靠背升高一点”“背部放低些” | 方向、幅度、角度 | 显示靠背调整动画和目标描述 |
| 腿板调节 | “把腿抬起来”“腿放平” | 方向、幅度 | 显示腿板模拟状态 |
| 整床升降 | “床升高一些”“把床降下来” | 方向、幅度 | 显示整床高度模拟状态 |
| 情景姿态 | “调到吃饭姿势”“我想坐起来看电视” | 场景姿态 | 将场景映射为预设姿态 |
| 复位放平 | “恢复平躺”“全部放平” | 无 | 进入二次确认，确认后模拟执行 |
| 连续微调 | “再高一点”“低一点”“就这样” | 上一床控意图、方向 | 继承最近一次床控上下文 |

床体大幅动作、整床明显升降和复位需要二次确认。确认期间识别“确认／可以／继续”“取消／不用／算了”；“停止”可在任何阶段直接打断。

### 二、照护协同

| 意图 | 典型表达 | 抽取参数 | 模拟响应 |
| --- | --- | --- | --- |
| 护理提醒 | “晚上八点提醒我吃药”“十分钟后提醒我喝水” | 事项、时间、重复规则 | 生成待确认的提醒卡，确认后模拟保存 |
| 护理记录 | “记一下我刚吃过药”“今天翻过几次身” | 动作、时间、查询范围 | 模拟新增记录或返回演示记录 |
| 应急呼叫 | “救命”“快叫护理员”“我需要帮助” | 求助对象、紧急程度 | 立即进入模拟求助流程，不要求二次确认 |
| 护理 Todo | “今天还有什么护理事项”“下午康复训练完成了” | 查询日期、事项、状态 | 返回或更新模拟任务列表 |

医疗诊断、药量变更和医嘱判断不在演示能力内。遇到“我该吃几片药”等表达时，Agent 明确说明不能替代医护判断，并建议联系护理人员。

### 三、关系链接

| 意图 | 典型表达 | 抽取参数 | 模拟响应 |
| --- | --- | --- | --- |
| 实时通话 | “给女儿打电话”“接听”“挂断” | 联系人、通话动作 | 模拟拨号、接听或结束状态 |
| 非实时留言 | “听听女儿的留言”“帮我给女儿留句话” | 联系人、播放或录制动作 | 模拟播放、录制和发送流程 |
| 纪念日祝福 | “今天谁生日”“给孙女送生日祝福” | 联系人、日期、祝福动作 | 返回演示纪念日或模拟录制祝福 |

联系人不存在或表达不明确时不猜测，要求用户说明联系人或在候选项中选择。

### 四、日常生活

| 意图 | 典型表达 | 抽取参数 | 模拟响应 |
| --- | --- | --- | --- |
| 今日事项 | “今天有什么安排”“下午要做什么” | 日期、时间段 | 返回演示日程 |
| 天气 | “今天天气怎么样”“明天会下雨吗” | 地点、日期 | 返回明确标注为演示数据的天气信息 |
| 帮助记事 | “记一下护工把眼镜放抽屉了”“我刚才记了什么” | 内容、时间、查询范围 | 模拟保存或查询记事 |
| 轻量陪聊 | “今天星期几”“陪我聊会儿”“讲个故事” | 话题、内容类型 | 给出简短温和回复，不做医疗判断 |
| 点播 | “播放京剧”“继续昨天的有声书”“声音小一点” | 内容、播放动作、音量、时长 | 模拟媒体播放与控制状态 |

## 识别与编排策略

### 处理优先级

1. 紧急停止；
2. 应急呼叫；
3. 待确认状态下的确认或取消；
4. 当前活动的控制，例如通话挂断、媒体暂停；
5. 明确业务意图；
6. 依赖上下文的连续表达；
7. 轻量陪聊或澄清提问。

### 规则型意图引擎

MVP 使用完全本地、可测试的规则引擎，不调用大模型：

- 文本标准化：去除多余空格和常见语气词，保留否定词、时间词和动作方向；
- 意图评分：每个意图由强关键词、普通关键词和正则模式组成，命中后累积分数；
- 冲突消解：按安全优先级、强模式、上下文相关性和分数排序；
- 槽位抽取：使用正则和词典提取联系人、时间、事项、床体部位、方向、幅度、媒体内容等参数；
- 置信度：根据强模式、关键词覆盖和必要槽位完整度生成高、中、低三档；
- 低置信度：不执行，返回一个聚焦的澄清问题和最多三个候选意图；
- 上下文：会话内只保存最近一次床控、当前待确认动作、当前通话或媒体状态，以及最近一次未完整请求；刷新页面后清空。

意图引擎必须是无浏览器依赖的纯 TypeScript 模块，以便单元测试覆盖同义表达、冲突表达、槽位抽取和上下文承接。

## Agent 处理过程展示

演示页将每次请求拆成以下阶段，并以时间线形式快速推进：

1. **听见**：语音转写或收到文本；
2. **理解**：识别功能域、意图和参数；
3. **安全检查**：判断是否需要确认、拒绝或立即执行；
4. **任务编排**：选择模拟技能和工具；
5. **反馈**：输出可理解的床侧语音回复与模拟结果。

确定性床控显示“规则路径”，提醒、通话和媒体显示“业务技能路径”，陪聊显示“对话路径”。这只是架构解释，不向用户伪装为真实设备日志。

## 页面组成

- **顶部状态区**：床端在线、离线语音可用、当前时间、返回家属端；
- **主交互区**：大型声波视觉、麦克风按钮、识别状态和文本输入兜底；
- **快捷示例区**：四个功能域各提供可点击示例，并支持切换更多示例；
- **会话区**：展示用户表达、Agent 回复、执行状态和确认按钮；
- **理解面板**：展示意图、参数、置信度、安全级别、模拟技能与工具；
- **能力地图**：常驻展示四个功能域及其子能力，当前命中的功能高亮；
- **演示声明**：明确“本页面仅模拟，不连接真实护理床或服务”。

视觉上沿用家属端的暖白、墨绿与柔和紫色体系，但采用更大的字号、更强的状态反馈和床旁终端式宽屏布局，与家属 App 保持关联又能一眼区分设备侧。

## 状态与数据流

```text
麦克风转写 / 文本输入 / 示例话术
                ↓
          文本标准化
                ↓
       安全优先级预判
                ↓
      意图评分与槽位抽取
                ↓
        上下文补全与消歧
                ↓
    确认 / 澄清 / 模拟技能执行
                ↓
  自然语言反馈 + 结构化理解结果
```

浏览器语音识别只负责产生文本，绝不直接触发模拟执行；所有输入都必须经过同一意图引擎。

## 错误与降级

- 不支持 Web Speech API：展示“不支持语音识别”，文本输入和示例话术继续可用；
- 麦克风权限拒绝：展示重新授权指引，自动聚焦文本输入；
- 没有检测到语音：保留当前会话，允许重试；
- 识别服务错误或网络问题：不丢失已转写文本，允许编辑后提交；
- 无法识别意图：不输出执行成功，转为澄清问题；
- 缺少必要参数：例如“帮我打电话”没有联系人时，询问联系人；
- 高风险或医疗请求：拒绝模拟不当操作，并给出联系护理人员的安全建议。

## 测试范围

### 单元测试

- 四大功能域的每项意图至少覆盖两种不同口语表达；
- “停止”和“救命”在混合表达中保持最高优先级；
- 床控连续指令正确继承上下文；
- 时间、联系人、床体部位、方向和内容槽位正确抽取；
- 大幅动作进入确认，小幅动作直接模拟执行；
- 低置信度和缺参数请求不会被错误执行；
- 医疗判断请求被安全拒绝。

### 组件测试

- 家属端链接正确指向独立页面并在新标签页打开；
- 文本提交后显示回复和结构化理解结果；
- 确认和取消能推进或终止待确认动作；
- 浏览器不支持麦克风时文本输入仍可用；
- 所有结果都带有模拟标识。

### 浏览器验证

- 桌面端和平板尺寸无横向溢出、遮挡或不可读文本；
- 允许麦克风时可进入监听状态；权限拒绝时正确降级；
- 快捷示例、文本输入、确认、停止、通话和媒体控制形成完整演示闭环；
- 控制台无相关错误，家属端原有核心交互不回归。

## 非目标

- 不连接真实 MCU、电机、床控协议或设备状态；
- 不发送真实电话、留言、提醒或应急通知；
- 不读取摄像头、健康数据或真实联系人；
- 不提供医疗诊断、药量建议或健康风险推断；
- 不将该页面包装成家属端远程床控功能；
- 不在本 MVP 中接入云端大模型或第三方语音供应商。
